# NuciCrunch

Juego de caramelos (match-3) con panel de administración.

- **Jugar en el navegador:** se publica con GitHub Pages (Settings → Pages → Source: *GitHub Actions*).
- **APK de Android:** se genera solo en cada cambio y queda en *Releases → NuciCrunch (APK más reciente)*.
- El juego está en `web/index.html`; el proyecto Android lo empaqueta tal cual.
